# Whiteout Survival Discord Bot

A lightweight, open-source bot for calculating Furnace and Camp upgrade costs in **Whiteout Survival**.
Built in response to requests from my Whiteout Survival alliance community.

## 🛠 Features

- `!furnace 30-1 FC3-2` – Total resources for furnace upgrades.
- `!camp 30-1 FC3-2` – Training camp resource calculator.
- `!upgrade 30-1 FC5 10` – Combined total with Zinman % discount(optional).

1. Clone the repo
2. Create `.env` file storing the TOKEN, ID
3. `pip install discord, dotenv` in the CLI
